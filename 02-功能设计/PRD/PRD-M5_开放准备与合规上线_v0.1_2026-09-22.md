# PRD-M5 安全隐私、开放准备与签证数据源接入（研发级）

- 版本：v0.1（2026-09-22，随 PRD 基线冻结）
- 里程碑：M5（V1 受控模式开放前的合规与工程就绪；依赖 M0–M4）
- 依据：V2 §6/§7/§9、D1–D9 决策手册、技术路线与架构方案 v0.1 §8/§9/§10、GP3 C14（全球通行）、Q6 结论、M1-16 数据源开关
- 成熟度：可进入研发排期；等保备案、签证数据授权、产品命名属外部依赖，按门管理，不以系统开发代替合规结论。

---

## 1. 目标与非目标

### 1.1 目标

1. 完成安全工程基线：认证授权、密钥与加密、审计链、备份恢复、依赖与镜像供应链、漏洞管理、日志脱敏、压测与容灾演练，达到等保二级启动条件（定级备案由公司法定流程完成，系统配合）。
2. 隐私交付物齐备：隐私政策/个人信息处理规则、跨境与门户 PIPIA、数据分类分级落地、保留与删除规则、主体权利响应（查询/更正/删除/撤回/可携带）、账号注销。
3. 全球通行（C14）在**授权落地后**接入真实签证/护照数据；未授权前维持框架态与示例数据，且不可对客上线（M1-16 开关延续）。
4. 影子运行 → 邀请制试点 → 受控放量的发布工程：环境与发布流水线、特性开关、数据 seed 治理、监控告警、应急与回滚预案、运营 SOP。
5. 产品命名、Logo 与应用商店上架材料定稿（现占位标识替换）。

### 1.2 非目标

| 不做 | 说明 |
| --- | --- |
| V1.5 有限开放（服务方自助注册、公开市场） | 另立变更；M5 只保证开关与数据结构不阻碍 |
| 双边平台化 V2 | 不在 V1 代码中预埋复杂平台逻辑 |
| 183 天税务居民判定、身份评测、生活成本 | 全球通行二期，需专门数据源与合规评估 |
| AI 自动填表/法律建议 | 不做；OCR 仅辅助预填（M3 已定） |
| 等保三级/金融级多活 | V1 目标为等保二级与同城备份；升级视业务规模 |
| 未授权数据的任何形式对客展示 | 硬禁止 |

## 3. 详细需求

### M5-01 安全基线

- **认证**：Keycloak OIDC 三 realm（员工 MFA、客户手机验证码、门户独立 realm + MFA）；敏感动作 step-up；验证码频控/锁定/防枚举（沿用 C01）；会话与令牌生命周期、刷新轮换、登出全端失效。
- **授权**：Casbin RBAC+ABAC 策略与代码同仓评审；每次发布自动导出"角色×资源×动作"矩阵快照；越权测试集（AT09/AT20/AT25 等）进 CI 必过。
- **密钥与数据**：KMS 信封加密；L3 独立桶、独立加密密钥、预签名 ≤2 分钟；密钥轮换流程（季度/离职触发）；数据库 RLS；备份加密。
- **审计**：哈希链校验任务（每日）、断链告警；WORM Object Lock 策略验证；审计留存期按法务确认（初始建议不少于 5 年，待 D 门确认写入配置）。
- **备份恢复**：PostgreSQL 每日全备 + WAL 增量；恢复演练每月一次并留记录；RPO/RDO 目标在 SLO 中声明（初始参数 RPO ≤24h、RTO ≤8h，影子期验证后定稿）。
- **供应链**：依赖锁文件 + 漏洞扫描（pnpm audit / OSV）、镜像签名与最小基础镜像、Secrets 扫描、Gitee 令牌轮换（**含本项目会话令牌，开工前必须轮换**）。
- **移动安全**：RN 包证书固定（TLS pinning）、root/越狱风险提示、截屏遮挡（L3 页面防截屏 FLAG_SECURE / iOS 模糊）、本地缓存加密、退出即清门户阅读器缓存。
- **Web 安全**：OWASP Top10 检查清单（含 XSS/CSRF/越权/上传/SSRF/限流）；上传只走对象存储直传与类型校验；管理后台 IP 白名单或零信任接入（按公司条件二选一，记录决定）。

### M5-02 监控告警与应急

- OpenTelemetry 链路 + Sentry；日志脱敏中间件（证件号/手机号/卡号/令牌正则与字段名双策略）；审计日志与业务日志分离存储。
- **SLO（初始目标，影子期校准）**：API 可用性 99.5%、T0 通知发送成功率 99%（失败必换道）、凭证上传成功率 99%、后台关键页 P95 < 2.5s。
- 告警：T0 发送失败/升级链断点、审计断链、主体门异常高频、门户越权、存储加密/备份失败、证书/资质到期（业务）。
- 应急预案：通道商故障、数据源下架、误发官方节点、资金相关页面错误、个人信息泄露；每案含处置人、冻结开关（特性开关可一键关闭：交易、门户、全球通行、T2）、客户告知模板（法务审核）。
- 压测：核心链路（初评、上传、看板、通知批量）目标并发按试点规模 3 倍设定（具体数值在试点客户数确定后由研发给出，不提前承诺）。

### M5-03 隐私交付物

- 隐私政策与个人信息处理规则：按《个人信息保护法》与 841 号令隐私义务编写，覆盖收集清单（按功能逐项映射 L1/L2/L3 字段）、目的、保存期限、共享方（境内主体/境外持牌方/通道商/电子签）、客户权利、投诉渠道；注册/合同/跨境共享三处同意版本化留痕。
- **PIPIA**：门户跨境共享、家庭授权、L3 材料托管三个处理活动各一份评估（D9 门核心输入）。
- App 内隐私中心：授权清单（家庭/跨境/营销/通知四类）、政策版本历史、访问记录入口（M3 同源）、权利申请入口。
- 未成年人：监护证据与最小化原则说明；非客户子女不采集。
- 法务定稿前：相关同意页用占位文本时，合同与跨境功能不得对客生效（与 M2/M3 门开关一致）。

### M5-04 保留、删除与注销

- **保留规则（初始建议表，法务确认后配置）**：
  - 合同/订单/收据/审计：法定保存期限内不删（建议 ≥5 年或法定期限从其规定）；
  - 案件材料 L3：案件结案 + 合同义务期满后按客户请求或到期策略删除/匿名化（默认建议结案后 3 年，待确认）；
  - 营销/行为数据：退订/注销后停止使用并按期删除；
  - 审计日志本身不可删改，到期按 WORM 策略归档/销毁并记录。
- **删除方式**：L3 对象安全删除（含备份的过期覆盖策略）、PII 匿名化（保留统计不可识别）、删除证明（给客户的受理回执，不承诺"数字世界彻底消失"，依法保留部分明确告知）。
- **账号注销**：本人 step-up → 在办业务校验（有生效订单/案件时告知影响，不阻止但需确认；资金/法定义务未结的依法保留范围列明）→ 冷静期（初始 15 日，可配置）→ 注销；注销后 T0/T1 法定通知仍依合同联系方式处理至案件终结。
- 撤回授权（M3）即时生效逻辑在此与注销/删除联动验证。

### M5-05 主体权利响应

- 查询、复制、更正、删除、撤回同意、可携带（机器可读导出，限客户本人提供的数据）统一走工单类型（复用 M4 工单），SLA 初始参数：受理 1 工作日、响应 15 工作日（法定要求从其规定，法务确认）；身份核验不通过转人工，不弱验证。
- 后台 A10 提供权利处理工作台：影响面预览（关联案件/法定义务）、执行动作（技术删除/匿名化由双人执行）、留痕与回执。

### M5-06 全球通行框架态与授权门（Q6）

- **框架态范围（M1 已上线）**：我的护照（手动维护护照信息，L2，不做 OCR 自动识别）、签证要求查询、护照对比与通行力排名三页结构；数据为显式【示例数据】，页面顶部常驻"示例数据，未对客提供决策依据"标识；后台 M1-16 开关。
- **授权门（对客上线全部条件，缺一不可）**：
  1. 数据源合同/授权落地（IATA Timatic 类或同等权威源，明确许可展示范围、缓存权、用户量/调用配额）；
  2. 数据处理协议与来源署名方式确认；
  3. 免责声明文案法务定稿（信息仅供参考、以官方为准、不构成移民建议）；
  4. 下架预案演练通过；
  5. D1 评分口径若在同期展示，评分表已发布。
- 门未过：功能在生产环境对客隐藏（不只是标示例）；已收藏/链接访问显"功能筹备中"。

### M5-07 签证/护照数据接入（门后工程）

- **服务端代理**：客户端不持数据源密钥；服务端按国/籍/护照类型查询，字段白名单映射（签证要求、停留期、材料概览、通行力分数口径按授权方原始口径，不自创排名算法）。
- **缓存与更新**：按授权允许的 TTL 缓存（初始建议 24h，遵从合同更严者）；数据版本与更新时间展示；排名类数据每次展示带数据日期。
- **对比**：护照对比仅做授权字段的并列展示，不做移民倾向推断；不与客户案件自动关联决策。
- **下架联动**：授权失效/欠费/合同终止 → 开关自动/手动关闭 → 前端回框架态（示例数据不对客）或下线页；缓存按合同要求清除并留清除记录。
- 用量监控与配额告警；来源页与免责声明常驻。
- **验收**：授权关闭演练在 30 分钟内完成全网下架；无任何页面残留真实数据（扫描断言）。

### M5-08 发布工程

- 环境：dev → test → shadow → prod；prod 变更走变更单（双人）；数据库迁移脚本可回滚或前向兼容。
- 特性开关（统一开关中心）：交易（M2 门）、门户/跨境（M3/D9 门）、结算（M4/D6 门）、全球通行（Q6 门）、T2 营销、电子签通道；开关状态与当前 D 门决策对照表在后台只读展示给管理员。
- CI（Gitee Go/Jenkins）：lint、类型检查、单测（core 状态机/金额/词库覆盖率红线，初始建议 ≥90%）、AT E2E（Playwright Web、Maestro/Detox RN）、安全扫描、构建产物签名。
- 移动发布：内测分发 → 商店审核；版本强制更新能力（含阻断版本号配置，仅限严重合规/安全问题使用）。

### M5-09 影子与邀请灰度

- **影子运行（初始建议 4–6 周，按数据质量调整，不承诺固定周期）**：员工与受邀非真实交易客户走全流程；每日核对：四级来源、送达回执、主体门、授权回收、审计链、词库命中；参数校准清单（各 PRD 初始参数统一收口）。
- **邀请制试点**：准入条件 = D1/D2/D4/D5/D8/D9 已拍板项对应门全部开放、等保备案已提交、隐私文件定稿、通道与数据源合同就位、控制矩阵签字；首批客户数量由公司按交付能力确定（系统不预设）。
- 试点期 P0 事件响应：任何"假成功/假官方/越权成功/T0 漏达/资金页面错误"立即停用相关开关，48 小时内复盘并决定恢复条件。
- 运营 SOP：内容发布、核验节拍、投诉值班、财务核验、门户审批、密钥与备份检查清单成册（文档产物，非系统功能）。

### M5-10 命名、品牌与上架

- 产品命名与 Logo 候选（现渐变圆角方块+路径勾选为占位）：商标可注册性核查 + 域名/应用名 availability 核查后定稿；设计系统 token 不变，替换资产。
- 上架材料：应用描述（不使用成功率类表述，过词库与法务双审）、隐私营养标签、账号删除声明（苹果/谷歌要求）、服务协议与隐私政策链接、年龄分级、境内外分发渠道按 D2 主体确定。

### M5-11 生产 seed 治理

- dev/test 允许示例数据（统一【示例】前缀与固定数据集）；prod 初始化脚本不含任何虚构顾问/客户/订单；部署流水线含"示例数据扫描"断言（示例姓名、示例单号模式），命中即阻断发布。

### M5-12 V1 出口验收（Definition of Done）

1. M1–M4 全部 AT 用例自动化通过 + 控制矩阵对照表 100% 覆盖；
2. 安全检查清单（M5-01）与一次外部渗透测试（建议；由公司采购，问题分级关闭）；
3. 隐私交付物、PIPIA、合同模板、D 门决策记录归档；
4. 备份恢复、应急、数据源下架三类演练记录；
5. 影子期参数校准报告与 SOP；
6. 命名/品牌/上架材料定稿；
7. 各方签字：产品、研发、安全、合规/法务、财务、运营。

## 5. 服务端/工程闸门清单

1. 未授权数据源：生产构建不含真实签证数据；开关关闭时相关路由返回 404/功能下线态。
2. L3 防截屏、加密缓存、阅读器退出清理在移动端 CI 用例中断言。
3. 审计哈希链每日校验；断链即告警并冻结导出。
4. 生产部署必经示例数据扫描与迁移检查。
5. 注销/删除动作双人执行且产生回执；法定保留数据显式标注保留依据。
6. 所有应急开关有权限、有审计、有恢复条件，无"一键清空"类危险操作。
7. CI 安全扫描高危漏洞为发布阻断项。
8. 隐私政策版本与同意记录可追溯到具体注册/合同时刻。

## 6. 验收用例（节选）

1. **Q6 下架演练**：关闭数据源开关后 30 分钟内三端无真实数据残留、缓存清除有记录、客户看到一致的下线说明。
2. **授权门保护**：合同未签状态下尝试启用全球通行对客展示，开关中心拒绝并提示缺失条件。
3. **注销闭环**：有在办案件客户的注销流程告知法定保留范围；冷静期后 T2/营销全停、L3 按策略处理、审计保留。
4. **权利请求**：可携带导出仅含客户本人提供数据且 L3 他人材料不含；删除双人执行与回执。
5. **备份恢复**：随机抽库恢复演练达成 RPO/RTO 目标并有记录。
6. **应急开关**：交易/门户/通行/T2 四开关演练，关闭后对应入口与接口同时不可用（前后端一致）。
7. **移动安全**：L3 页面截屏/录屏被系统遮挡；越狱设备给出风险提示（不阻断基础浏览）。
8. **供应链**：高危依赖漏洞构建失败；轮换后的 Gitee 令牌在仓库历史与配置中检索为零（新令牌不入仓）。

- 安全与隐私能力随 M2–M4 同步建设（不是最后补），M5 做的是验证、演练与外部确认。
