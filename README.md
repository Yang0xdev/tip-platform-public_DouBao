# 透明化身份规划服务平台（产品工作名）

一款"打破移民行业壁垒"的**受控、透明、可追溯**的身份规划（移民）服务平台。
最终形态：**一个统一总后台 + 两个终端（客户服务端 App、顾问展业端 App / iPad）**。

> 本仓库保存全部产品设计文档与高保真可点击原型，用于版本管理、随时调用与备份。
> Gitee 仓库（私有）：https://gitee.com/yang_bj/transparent-identity-platform
> 所有国别、项目、费用、顾问、签证数据均为**虚构示例数据**，不构成移民/税务/法律建议；上线前须经执业律师与持牌方核验。

## 不可越过的产品红线（原型与开发都必须遵守）

1. 不做成功率/获批率展示，不做百分比进度条；初评只输出"符合 / 差距 / 待确认 / 未承诺"。
2. 进度时间线四级来源：客户提交 / 公司审核 / 服务方报告 / 已核验官方凭据；"待核验"≠到账，公司动作≠官方受理。
3. 费用必须分项、写明收取方、确定/估算、币种；异币种不相加；主体不一致不能下单。
4. 透明≠隐私公开：家庭成员默认互不可见，授权按"人员×案件×动作×有效期"，原件访问留痕、服务方门户水印。
5. T0 关键节点多通道通知 + 送达回执 + 失败换通道/升级；投诉独立受理。
6. 全球通行模块仅提供短期旅行签证信息，不等于居留/工作/移民；第三方数据须授权并署名，授权失效即下架。
7. 资金/合规/生命健康类动作保留有资质的人工责任，不用"智能化"替代责任主体。
