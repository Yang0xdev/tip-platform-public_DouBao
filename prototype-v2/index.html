原则原型里的具体表达
不把预估写成保证初评只输出"符合/差距/待确认/来源"，无获批率；参考周期标注"非承诺"，不做百分比进度条。
不把后台动作写成官方动作进度时间线分四色来源：客户提交 / 公司审核 / 服务方报告 / 已核验官方凭据；"待核验"不等于到账。
透明≠隐私公开家庭成员不默认互可见，授权按 人员×案件×动作×有效期；服务方门户水印、下载需审批。
每项承诺配对控制动作与责任人费用必写收取方、主体不一致不能下单；T0 通知多通道+送达回执+升级；投诉独立受理。

★贯穿全程的五道硬闸门与边界

发布门
事实无核验记录不得发布；编辑≠发布。
主体门
签约 / 交付 / 收款三要素不一致即阻断下单。
凭据门
官方节点以凭据核验为准，核验人≠发起人。
T0 时限门
多通道 + 送达回执 + 失败换通道 / 升级。
授权与审计门
人员×案件×动作×有效期；服务端逐项校验。
后台能力边界是「配置 / 核验 / 发布 / 留痕」：官方进度、到账、签证决定、获批结果只能登记凭据并核验，任何终端都不能手工改写成承诺或结果。
