## 一、本期交付范围（已上线、已验证）

### P2-1 PDF 上传与解析
- A14「采集」区新增 **上传数字 PDF**：浏览器读取为 base64 → `POST admin/refinery/sources/ingest-pdf` → pdfjs 服务端解析版面块；
- 扫描件（无文本层）如实标记"待视觉模型"，不伪造内容；浏览器侧 Qwen-VL 通道接口（`sources/:id/blocks`）已预留。

### P2-2 本地 LLM 混合抽取增强
- 新增 `llm-extractor.service.ts`：
  - 短超时探测本机 Ollama，按 qwen2.5:7b → qwen3:7b → 3b → 0.5b 偏好选模；
  - 两阶段 JSON 抽取（temperature=0），**evidence 必须逐字锚定版面块，不锚定不采信**；
  - 与确定性结果交叉验证：一致置信 +0.04（上限 .98）；不一致**保留确定性值并记录 disagreements**（保守，不降级）；确定性缺失而 LLM 有锚定则采信；
  - 本机 LLM 不可达自动走纯确定性通道，响应不中断。
- `extractModel` 字段如实记录 `hybrid: <model> + deterministic` 或 `deterministic（本地 LLM 不可用）`。

### P2-3 批量接入与冻结交付
- A14 新增 **文件夹批量导入**（.txt/.md/.html）→ `sources/ingest-batch`，自动跑到待复核，重复内容按指纹跳过；
- 七工段流程修正：复核通过（四眼，reviewer ≠ submitter）与 **发布到 L1** 拆为两个显式工段，UI 均已闭环；
