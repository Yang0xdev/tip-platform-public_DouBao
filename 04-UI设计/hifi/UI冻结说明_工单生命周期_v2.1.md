### 工单全链路（客户端 → 后台 → 客户端）

1. 客户端「服务」tab →「新建工单」：四类（咨询/疑问/资料变更/投诉），
   标题与描述必填，提交后在「我的工单」即时出现（submitted）。
2. 总后台 A08「工单投诉」：
   - 客服队列：submitted → **受理（accept）** → accepted →
     **处理（process）** → processing → **解决（resolve，处理结果说明必填）** →
     resolved_pending → **关闭（close）** → closed；
   - 投诉队列：投诉工单仅出现在合规队列（物理隔离），被投诉顾问回避。
3. 客户端重新进入「服务」：工单状态同步显示 closed。
