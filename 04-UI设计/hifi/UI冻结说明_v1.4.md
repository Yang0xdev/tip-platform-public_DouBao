# UI 冻结说明（FREEZE v1.4 · 精修版）

冻结日期：2026-09-29
基线：v1.3（2026-09-22 冻结，Gitee tag `hifi-v1.3`），本版为**视觉精修，不改布局、不加功能**。
用户口径：不逐屏确认，统一升级后一次性展示；精修完成后本稿为唯一视觉基线。

## 本次精修内容（v1.3 → v1.4）

1. **质感统一**：卡片悬浮/按压过渡全站同源（.28s cubic-bezier(.16,1,.3,1)），hover 抬升 2px + sh2，active 回弹；
2. **按钮扫光**：navy/berry 主按钮增加克制的对角高光扫过（hover 触发，单次），保留原渐变与内阴影；
3. **渐变节奏穿插**：
   - 总后台：品牌标识改为签名渐变、顶栏底部 2px 渐变细线、当前导航项渐变指示条；
   - 顾问端：工作台新增渐变问候横幅（展业工作台 · 三原则）；
   - 客户端/门户：保持既有渐变 hero 与品牌标识；
4. **状态完备工具类**：`.skeleton`（shimmer 1.5s 骨架屏）、`.statebox`（空态/错误态统一容器与图标位）、`.gradline`（流动渐变分隔线）；
5. **无障碍**：`:focus-visible` 莓红描边、文本选区 navy-50、reduced-motion 下骨架/渐变动画全部停用；
6. 版本标识统一更新为 v1.4。

## 冻结内容（继承 v1.3，精修项见上）

1. **设计 Token**：Navy `#002661`、Berry `#AF2D67`，签名渐变 `linear-gradient(132deg,#AF2D67 0%,#5E246B 46%,#002661 100%)`；中性色、语义色、阴影 sh1/sh2、圆角体系（卡片 18、按钮 22/18、胶囊 999）、Manrope + Noto Sans SC；
2. **动效契约**：页面切换 420ms cubic-bezier(.22,1,.36,1)；元素分层 rise 入场；Tab 活动胶囊 spring；按钮按压缩放；签名渐变 drift 16s；T0 红态脉冲；`prefers-reduced-motion` 兜底；
3. **版式与结构**：手机壳（深色边框 42px 圆角）、底部 Tab 数量与命名（客户端 6 tab、顾问端 5 tab）、各屏信息层级与组件用法；
4. **舞台背景**：浅灰蓝 `#E9EDF3`，不使用深色舞台。

## 变更控制

- 冻结后任何视觉改动（颜色、圆角、间距、布局、组件形态、动效曲线、Tab 结构）**禁止直接改代码**；
- 流程：提出 → 影响面（产品+设计+研发+合规）评估 → 升版（v1.5）并登记 → 同步更新本说明与 tag → 才允许改动；
- 已归档的偏离版本（`05-代码/demo/归档-偏离版-v1/`）不得回流。

## 开发使用方式

- RN 侧 `packages/ui-native/src/tokens.ts` 必须与本冻结 Token 一致；
- 前端实现以本目录对应文件为视觉验收基准，逐屏比对；
- 视觉差异按缺陷处理，不允许“开发阶段先简化”。
