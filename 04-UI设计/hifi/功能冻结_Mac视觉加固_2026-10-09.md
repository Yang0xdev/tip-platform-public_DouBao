## 本次交付（增量，不改动既有功能）

1. **A14 本机视觉环境自检面板**
   - 一键检测浏览器 → 本机 Ollama 连通性、已装模型清单、视觉模型就绪状态
   - 失败时给出可执行原因（未启动 / 未放行 OLLAMA_ORIGINS / 缺 VL 模型）
   - 面板内入口直达《Mac 配置图文指引》

2. **视觉转录逐页校对弹窗（人工质检门）**
   - 转录完成后不再直接入库，先弹窗逐页展示全部版面块
   - 每块可：改文字、改类型（标题/段落/清单/表格）、删除误识别块
   - 「确认并继续工段」才回传 blocks 并自动跑到待复核

3. **新增 /mac-vision 图文配置页**
   - 5 步：brew install ollama → pull qwen2.5vl:7b → launchctl setenv 放行并重启 → 自检 → 解析
   - 常见问题表、安全提示、命令一键复制

4. **服务端修复：body 体积上限**
   - Express 默认 100kb 导致 PDF base64 上传 413；放宽 json/urlencoded 至 25mb
   - express 增补为 @tip/api 直接依赖

## 关键实测结论（云端 VM，qwen2.5vl:3b，纯 CPU）

| 变量 | 结果 |
|---|---|
| JPEG（canvas，q0.82/0.9） | 压缩伪影使 3b 把整页**合并为 1 块**或只输出标题 |
| **PNG（无损，约 278KB/页）** | **10 块全部正确分块、类型正确、零漏字** |
| 长规则 prompt | 3b 只输出标题（过度约束） |
| **极简 prompt**（逐字转录，只输出 JSON：{blocks:[…]}） | 稳定正确分块 |
| CPU 单页耗时 | 155–198 秒（含模型加载；用户 Mac Apple Silicon + 7b 会显著更快） |

结论已同步写入《本地AI部署指南》视觉解析章节与 local-ai-data-factory skill runbook。
