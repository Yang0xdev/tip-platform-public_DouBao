# 05-代码（工程实现区，暂未启用）

本目录保存未来正式工程代码。**在以下前置条件满足前不进入开发**：

1. 高保真 UI 逐屏批注完成并视觉定稿；
2. G-P0 商业合规决策门 D1–D9 落定（试点国别、境内签约/备案主体、境外持牌供给 ext/in、收费与资金路径、跨境数据法定路径）；
3. 研发级 PRD 与技术方案评审通过（接口、状态机以 `02-功能设计/GP4_核心对象与状态机` 为准）；
4. Q6 全球通行数据源授权未落实前，该模块只建框架、不对客上线。

## 规划中的仓库结构（技术方案定稿后可调整）

```
05-代码/
├── client-app/        # 客户服务端 App（iOS/Android 或跨端框架，待定）
├── advisor-app/       # 顾问展业端（手机 + iPad 双形态）

└── packages/          # 共享设计 token、组件库、校验规则（红线与 AT19–AT26 的机器阻断实现）
```

## 开发铁律（继承产品红线）

- 所有闸门（主体三要素、T0 升级、授权范围、家庭授权、门户越权）必须**服务端强制**，前端控制只作体验；
- 无成功率/获批率；费用分项收取方、异币种不相加；待核验≠到账；
- 佣金六态、授权闭环、素材白名单、门户水印与到期回收按 GP3/GP4 与 AT19–AT26 实现；
- 所有高保真稿中的数据均为虚构示例，开发时不得作为真实配置上线。
