02一次写请求如何穿过闸门

认证 → 授权 → 校验 → 状态机守卫 → 事务（业务表 + 事件 + outbox）→ 审计。任一环节拒绝即返回并留痕。
认证OIDC · MFA · 设备
限流幂等版本 · 重复拦截
授权 PEP身份×关系×动作×分级
应用校验金额 · 词库 · 同意
状态机守卫合法迁移 · 职责分离
事务执行投影 + 事件追加
Outbox通知/佣金/回收
哈希链审计前后值 · 原因
红色边框 = 业务红线闸门，服务端唯一裁决，前端置灰仅为体验
硬编码在守卫层的职责分离：核验人 ≠ 案件发起人；编辑 ≠ 核验 ≠ 发布；结算双人复核；财务不见证件原件；投诉调查人 ≠ 被投诉顾问。主体三要素不一致时，客户下单/付款、顾问发起、财务核验四个入口共享同一阻断判定，无强制通过参数。

03状态机 + 事件溯源（不静默改写）

状态迁移规则集中在共享 core 包（纯函数），后端裁决、移动端演示同一份；更正以更正事件保留原值。

只追加的事件流

<agg>_events：from→to · actor · reason · prev_event_id

case.accepted_off · 凭据+核验人
material.corrected · 原值/新值/审批
grant.expired · 调度器自动回收

投影（当前状态）

reducer(state, event) 事务内维护主表
订单：合同态 / 到账态 / 服务态三态分离
佣金：六态，不可跳步
授权：五步，到期停新接旧

Outbox 外发（同事务）

通知 · 佣金应计 · 门户回收 · 审计归档
T0：App 未读 → 短信 → 人工电话 → 主管
升级绝不改写原截止时间
Worker 轮询，至少一次 + 幂等消费

04数据分级与 L3 隔离

默认最小可见：顾问只见材料状态，服务方只在线看水印影印件，跨境共享单独同意且法定路径确认前 L3 不出境。

L1 公开内容

  • 已发布项目、名片白名单字段
  • 防骗教育、核准素材
  • CDN 缓存，下架转历史只读

L2 业务数据

  • 方案、订单、工单、跟进
  • 按服务关系 / 岗位行级过滤
  • 内部备注不对客投影

L3 高敏信息

  • 证件 / 资产 / 监护材料 / 无犯罪 / 凭证
  • 独立加密桶 + KMS，字段级加密掩码
  • 查看授权、下载审批、水印、留痕、到期回收
