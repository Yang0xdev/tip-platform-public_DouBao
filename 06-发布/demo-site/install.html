把 App 装到手机或电脑

客户端与顾问端已支持 PWA 安装：iPhone 从 Safari 添加到主屏幕，即出现 App 图标、 全屏运行、无浏览器地址栏；电脑 Chrome/Edge 可安装为独立窗口应用，并支持离线打开已缓存页面。

iPhone / iPad

添加到主屏幕

请使用系统自带 Safari 浏览器
  1. 用 Safari 打开要安装的 App 链接（客户端或顾问端）。
  2. 点击底部「分享」按钮（方框向上箭头）。
  3. 下滑选择「添加到主屏幕」，点右上角「添加」。
  4. 回到主屏幕，点击 App 图标即可全屏使用。
电脑 Chrome / Edge

安装为桌面应用

Windows / Mac 均可
  1. 用 Chrome 或 Edge 打开 App 链接。
  2. 地址栏右侧出现「安装」图标，点击它； 或从右上角菜单选择「安装"透明身份规划"」。
  3. 确认安装后，桌面与开始菜单生成应用图标。
  4. 双击即在独立窗口运行，无浏览器标签栏。
安装客户端 安装顾问端 返回演示首页

说明：首次安装需联网打开一次以完成缓存；离线时可打开已缓存页面， 实时数据会如实提示网络错误、不做假数据。iOS 若长期不使用，系统可能回收缓存，重新打开即可恢复。
