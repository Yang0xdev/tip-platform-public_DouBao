Mac 本机视觉解析 · 一键配置

让后台 A14 的扫描件由你 Mac 上的 Qwen-VL 逐页转录。图像只在浏览器与本机 Ollama 之间传输，不上云、不产生任何费用。

下载一键配置脚本（mac-setup.zip）

推荐方式：双击自动完成（约 1 分钟 + 模型下载）

  • 下载并解压上面的 mac-setup.zip，得到 mac-setup.command
  • 双击运行；若提示“无法打开（来自身份不明的开发者）”，对文件右键 → 打开 → 打开即可
  • 脚本自动完成：安装/启动 Ollama → 放行演示站点 → 安装 Chrome 安全通道（开机自启）→ 拉取视觉模型 → 自检；看到“全部就绪”即完成
脚本可重复运行（幂等），不使用 sudo；模型已存在会自动跳过下载。新版脚本自动安装一个仅监听本机的「安全通道」，Safari 与 Chrome 均可直接检测和解析。
请在 Mac 的 Safari 或 Chrome 中操作（App 内置浏览器运行在云端，访问不到本机）。若你之前跑过旧版脚本、Chrome 仍连不上，请重新下载本页最新脚本再运行一次。

运行完脚本？点这里即时检测

检测直接从浏览器访问你本机的 127.0.0.1:11434，结果只显示在本页，不上传任何信息。

检测本机视觉环境
手动配置（仅 Safari 适用，共 5 步；Chrome 请用上方一键脚本）

1安装并启动 Ollama

brew install ollama # 或官网 ollama.com 下载，启动菜单栏 App

2拉取视觉模型（约 5GB）

ollama pull qwen2.5vl:7b ollama list # 确认列表里有 qwen2.5vl:7b
内存 16GB 的 Mac 跑 7B 完全可用；首次推理会慢一些（模型加载），之后逐页约十几秒。

3放行演示站点（关键，否则浏览器被拦截）

launchctl setenv OLLAMA_ORIGINS "https://demo.hbwhere.com,http://localhost:5100" launchctl setenv OLLAMA_HOST "127.0.0.1:11434"
  • 执行后退出菜单栏的 Ollama 再重新打开（环境变量才生效）
  • 验证：终端运行 curl http://127.0.0.1:11434/api/tags，能看到模型 JSON 即正常
终端一行命令也可直接跑脚本：bash -c "$(curl -fsSL https://demo.hbwhere.com/mac-setup.command)"

4回到后台自检并解析

  • 打开 A14，点「检测本机视觉环境」，显示“Ollama 已连通 · 视觉模型就绪”
  • 在「① 采集」上传扫描 PDF → L0 队列该行点「浏览器视觉解析」
  • 逐页转录完成后，在弹窗里校对（可改字、改类型、删误识别块）→「确认并继续工段」
  • 资料自动跑到待复核，四眼通过后发布到 L1

!常见问题

现象处理
双击 .command 被拦截对文件右键 → 打开 → 打开；或用上面的终端一行命令
自检提示“Ollama 未连通”Ollama 未启动，或第 3 步后未重启 Ollama
提示“未发现视觉模型”执行 ollama pull qwen2.5vl:7b，或重跑脚本
Chrome 报 CORS / 网络错误 / 被阻止Chrome 的私有网络安全策略（PNA）要求本地安全通道：重新运行本页最新一键脚本即可；或改用 Safari
豆包等内置浏览器连不上内置浏览器在云端运行，访问不到你电脑；请用系统 Safari/Chrome
转录内容明显错乱确认用的是 qwen2.5vl:7b 而非小模型；扫描件尽量清晰、正向
超过 12 页未处理单次上限 12 页，把 PDF 拆分为多个文件分别解析
安全提示：本功能只在你本机完成；请勿在公共/他人电脑上配置，避免扫描件被他人访问。
