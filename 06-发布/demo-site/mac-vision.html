Mac 本机视觉解析 · 5 分钟配置

让后台 A14 的扫描件由你 Mac 上的 Qwen-VL 逐页转录。图像只在浏览器与本机 Ollama 之间传输，不上云、不产生任何费用。

1安装并启动 Ollama

brew install ollama # 或官网 ollama.com 下载，启动菜单栏 App

2拉取视觉模型（约 5GB）

ollama pull qwen2.5vl:7b ollama list # 确认列表里有 qwen2.5vl:7b
内存 16GB 的 Mac 跑 7B 完全可用；首次推理会慢一些（模型加载），之后逐页约十几秒。

3放行演示站点（关键，否则浏览器被拦截）

launchctl setenv OLLAMA_ORIGINS "https://demo.hbwhere.com,http://localhost:5100" launchctl setenv OLLAMA_HOST "127.0.0.1:11434"
  • 执行后退出菜单栏的 Ollama 再重新打开（环境变量才生效）
  • 验证：终端运行 curl http://127.0.0.1:11434/api/tags，能看到模型 JSON 即正常

4回到后台自检并解析

  • 打开 A14，点「检测本机视觉环境」，显示“Ollama 已连通 · 视觉模型就绪”
  • 在「① 采集」上传扫描 PDF → L0 队列该行点「浏览器视觉解析」
  • 逐页转录完成后，在弹窗里校对（可改字、改类型、删误识别块）→「确认并继续工段」
  • 资料自动跑到待复核，四眼通过后发布到 L1
前往后台 A14

!常见问题

现象处理
自检提示“Ollama 未连通”Ollama 未启动，或第 3 步后未重启 Ollama
提示“未发现视觉模型”执行 ollama pull qwen2.5vl:7b
浏览器报 CORS / 网络错误OLLAMA_ORIGINS 未含 https://demo.hbwhere.com，改后重启
转录内容明显错乱确认用的是 qwen2.5vl:7b 而非小模型；扫描件尽量清晰、正向
超过 12 页未处理单次上限 12 页，把 PDF 拆分为多个文件分别解析
安全提示：本功能只在你本机完成；请勿在公共/他人电脑上配置，避免扫描件被他人访问。
